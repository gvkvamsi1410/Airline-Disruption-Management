# IROP tail-swap recovery demo — dependencies

# Python: 3.12 recommended. 3.13 also works for this (the MIP uses docplex.mp,
# not docplex.cp, which is the part that doesn't support 3.13 — you'll see a
# harmless RuntimeWarning about it at import time; it's suppressed in irop/__init__.py).
#
# Tested and verified working with exactly these versions (2026-09):
#   cplex 22.2.0.0 · docplex 2.31.254 · dse-do-utils 0.5.8.1b1
#   dash 4.2.0 · dash-bootstrap-components 2.0.4 · plotly 6.3.0
#   pandas 2.3.3 · pandera 0.31.1 · openpyxl 3.1.5 · sqlalchemy 2.0.43
# If `pip install -r requirements.txt` pulls newer versions and something
# breaks, pin to the versions above as a fallback.

                            # the Community Edition — no IBM account or license

                            # constraints combined; this model uses ~226 / ~590,
                            # comfortably inside that, so CE is all you need.

                            # (the "Victor's framework" the model is built on)

                            # internally; works but is noisy, so pinned off for now
numpy>=1.24
openpyxl>=3.1               # read/write the scenario workbook (IropInputs.xlsx)
pandera>=0.18                # validates the input tables on load

# dashboard
